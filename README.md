# Казино-зал

Мультиплеер для друзей на виртуальных фишках: Краш, рулетка, апгрейдер, Верити, бомба в банке, пул и техасский холдем. Реальных денег нет.
План и правила: [PLAN.md](PLAN.md).

## Быстрый запуск (Windows)

Двойной клик по `start.bat`. Откроется окно-пульт: он сам запускает сервер и туннель cloudflared и показывает
- ссылку для друзей `https://….trycloudflare.com` (появится секунд через 10, при каждом запуске новая) с кнопками «Копировать» и «Открыть»;
- админку на этом компьютере (http://127.0.0.1:3000/admin.html);
- админку с телефона через туннель и кнопку, копирующую токен админки.

Кнопки «Новая ссылка», «Перезапустить сервер», «Выключить зал». Закрыть пульт = выключить зал аккуратно, как Ctrl+C: фишки со столов вернутся игрокам. Если зал уже запущен (например, Claude), пульт подхватит его и его ссылку. Журналы сервера и туннеля: `data/logs/`.

## Запуск

Нужен Node.js 20+.

```bash
npm install
node server/index.js
```

(`npm start` делает то же самое; в PowerShell с запретом скриптов используй `node server/index.js` или `npm.cmd start`.)

Открыть http://127.0.0.1:3000. Чтобы проверить мультиплеер локально, открой вторую вкладку в режиме инкогнито (игрок привязан к браузеру через `localStorage`).

Остановка: `Ctrl+C` (несохранённые изменения дописываются в файл перед выходом).

Тесты:

```bash
npm test
```

## Данные

Балансы лежат в `data/players.json` (создаётся сам, в git не попадает). Запись с дебаунсом 0,5 с, атомарно через временный файл.

- Сбросить всех: остановить сервер и удалить `data/players.json`.
- Поправить баланс вручную: остановить сервер, отредактировать файл, запустить.
- Фишки, которые лежали на столе или в ставке Краша, тоже пишутся в файл (`reserved`). Если сервер упал или его убили без Ctrl+C, при следующем старте они вернутся в баланс.
- Если файл повреждён, сервер не стартует и говорит об этом, а не обнуляет фишки молча.
- Игрок, очистивший браузер, теряет доступ к своему имени: токен хранится только у него. Перенести можно, скопировав `casino.token` из `localStorage` старого браузера.

Переменные окружения:
- `PORT`: порт (по умолчанию 3000).
- `HOST`: адрес (по умолчанию `127.0.0.1`, снаружи сервер не виден). `HOST=0.0.0.0` откроет его для локальной сети.

## Друзья по ссылке (cloudflared)

Установить один раз (Windows):

```bash
winget install --id Cloudflare.cloudflared
```

После установки открой новый терминал, чтобы `cloudflared` появился в PATH. Запуск во втором терминале, пока работает `npm start`:

```bash
cloudflared tunnel --url http://127.0.0.1:3000
```

В выводе появится ссылка вида `https://xxxx.trycloudflare.com`. Её и отправляй друзьям.

- Если в логе повторяется `failed to dial to edge with quic: timeout`, сеть режет UDP. Запускай через TCP:
  `cloudflared tunnel --protocol http2 --url http://127.0.0.1:3000`
- Ссылка новая при каждом запуске cloudflared. Для постоянной нужен именованный туннель с аккаунтом Cloudflare.
- В команде именно `127.0.0.1`, а не `localhost`: на Windows `localhost` может уйти в IPv6 (`::1`), а сервер слушает только IPv4.
- WebSocket через туннель работает сам: клиент берёт адрес из текущей страницы (`wss://` на https).

## Админка

Открой на этом компьютере http://127.0.0.1:3000/admin.html, вход без пароля.

- Фишки: дать или забрать выбранному, всем онлайн или всем; сделать баланс ровно N.
- Игрок: переименовать, мут в чате, сбросить таймер пособия, выгнать из-за стола.
- Краш: видна секретная точка краха текущего раунда; подкрутить краш (во время ставок меняет текущий раунд, иначе следующий); крашнуть сейчас.
- Покер: видны кубики всех; подкрутить кубики игроку на ближайший бросок (раздача или перебросок).
- Приколы: объявление баннером на весь экран или в чат, эффекты всем или одному (конфетти, денежный дождь, тряска, переворот экрана, дискотека).
- Музыка из папки `music`, кнопка «Очистить чат», удаление игроков, подкрутка рулетки.

С другого устройства (через туннель) админка просит токен: содержимое `data/admin.token`, создаётся при первом старте и в git не попадает. Без токена API отвечает 403.

Всё то же доступно через API `/admin/api/*` (см. `server/admin.js`), например:

```bash
curl -X POST http://127.0.0.1:3000/admin/api/grant -H "content-type: application/json" -d "{\"target\":\"online\",\"amount\":15000}"
```

## Музыка

Положи mp3 (или m4a, ogg, wav) в папку `music` в корне проекта: она создаётся сама при запуске и в git не попадает. Треки сразу появятся в админке в карточке «🎵 Музыка». Нажал трек, и он играет у всех онлайн синхронно; кто зайдёт позже, попадёт в то же место. У каждого игрока внизу экрана громкость и кнопка «выключить у себя».

## Фоновый джаз

Тихий генеративный джаз и блюз играет у каждого игрока сам: `public/lounge.js` синтезирует его в браузере (Web Audio), аудиофайлов нет. 13 треков-партитур (джазовый блюз, босса-нова, баллады, шаффл, модальный джаз); ансамбль каждый раз импровизирует заново. Кнопка 🎷 в правом нижнем углу: пауза, следующий трек, громкость, выключение (запоминается). Пока играет песня из зала, фон затихает.

## Защита

- Все расчёты и случайность на сервере, клиент только шлёт команды. Суммы проверяются на целое и диапазон.
- Лимит частоты: 20 сообщений подряд, дальше 10 в секунду; после 100 отброшенных соединение закрывается. Чат: 5 подряд, дальше 1 сообщение в 2 секунды.
- Не больше 10 новых игроков в час с одного адреса (через туннель берётся из `CF-Connecting-IP`).
- Чужие кубики уходят клиентам только при вскрытии, точка краха только после краха.

## Структура

```
server/
  index.js     express + ws, роутинг сообщений
  players.js   игроки, балансы, пособие, рейтинг, хранение в JSON
  admin.js     API админки
  crash.js     Краш: раунды, ставки, вывод
  holdem.js    Покер: Техасский холдем (комбинации, ставки, побочные банки)
  bomb.js      Бомба в банке
  upgrader.js  Апгрейдер
  requests.js  заказы песен
  rng.js       вся случайность через crypto
public/
  index.html, style.css, client.js   зал
  admin.html, admin.css, admin.js    админка
test/
  тесты на каждую игру и админку (npm test)
```
