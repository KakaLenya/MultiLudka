                                        🔐 Доступ

                                        С этого компьютера по адресу http://127.0.0.1:3000/admin.html админка открывается без токена. С телефона или другого компьютера нужен токен из файла data/admin.token; он запоминается в браузере.

                                        ⏻ Выключить сервер

                                        Зал закроется аккуратно, как по Ctrl+C: фишки из игр вернутся игрокам. Снова запустить можно только на компьютере с сервером (node server/index.js).
